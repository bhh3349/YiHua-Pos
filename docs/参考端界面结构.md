# 扫呗餐饮收银 · 实际界面结构（逆向记录）

> 来源：实操参考端 `SaoBei.Cashier.Catering.exe`（v1.2.2.2），
> 通过 UI Automation 读取真实控件树 + PrintWindow 截图。
> 用途：逸华收银的布局与流程对齐依据。**只抄流程和布局，不抄视觉。**

## 一、菜单结构（点左上「☰ 菜单」展开）

### 经营
| 项 | 说明 |
|---|---|
| 桌台点餐 | 正餐模式：先开台再点菜 |
| 直接点餐 | 快餐模式：不选桌，直接点 |
| 接单叫号 | 取餐号模式 |
| 订单 | 查单、退菜、反结账、补打 |

| 沽清 | 菜品沽清 / 解除沽清 |
| 交班 | 开班、交班、交班记录 |
| 服务市场 | 增值服务（外卖平台对接等） |
| 小蓝店长 | 平台自带 AI 助手 |

### 管理
| 项 | 说明 |
|---|---|
| 统计 | 报表 |
| 会员 | 会员管理 |
| 打印 | 打印机、档口、票据模板、打印记录 |
| 设置 | 门店、收银规则、设备、账号权限 |

**模式三选一**：桌台点餐 / 直接点餐 / 接单叫号，当前模式在菜单里高亮。

### 关键结论

1. **商品区在右、购物车在左** —— 和逸华现在的实现正好相反。
2. **操作按钮是中间一条竖排**（103px 宽），不是横排。
3. **支付方式是购物车左下角三个大按钮**，不是单独一页。
4. **单屏完成全部点餐动作** —— 没有「点单页 → 收银页」的跳转，
   点菜、改量、备注、打折、收款全在同一屏。
5. **堂食/外带是顶部单选**，不是订单属性。
6. **餐牌号（取餐号）在购物车顶部**，快餐模式直接用。
7. 购物车为空时中间是**问候语 + 广告位**（不是空白，也不是"暂无数据"）。

## 四、顶栏

| 元素 | 说明 |
|---|---|
| ☰ 菜单 | 展开全部应用面板（左侧抽屉 375px 宽） |
| 店内点餐 / 接单叫号 | 模式切换（RadioButton） |
| 试用中 / 剩余N天 | 授权状态 |

| 4 个图标按钮 | 打印队列 / 锁屏 / 最小化 / 关闭 / 用户 |

## 五、菜单抽屉

- 左侧抽屉，宽 375px，从 (19,114) 起
- 分两组：**经营**（8 项 + 小蓝店长）、**管理**（4 项）
- 每项 176×64，两列排布
- 当前模式项有蓝色边框高亮
- 底部有广告位（可关闭）

## 六、和逸华当前实现的差异清单

| 项 | 扫呗 | 逸华现状 | 要不要改 |
|---|---|---|---|
| 商品/购物车左右 | 商品右、车左 | 商品左、车右 | **改**（对齐习惯） |
| 操作按钮 | 中间竖条 103px | 明细下方横排 | **改** |
| 支付方式位置 | 车左下角三按钮 | 独立收银页 | **改** |
| 点餐与收款 | 同屏 | 两个页面 | **改** |
| 模式切换 | 顶栏 RadioButton | 左侧导航两项 | **改** |
| 餐牌号 | 有 | 无 | 加 |
| 堂食/外带 | 顶部单选 | 无 | 加 |
| 制作中计数 | 有 | 无 | 加 |
| 会员登录入口 | 车顶部 | 无（会员二期） | 预留 |
| 空购物车 | 问候+广告位 | 空白 | 加问候语 |

## 八、没抄的部分（明确不做）
