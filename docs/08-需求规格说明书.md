# 逸华餐饮收银 —— 需求规格说明书

> 版本 v1.0 · 四端产品：Windows 收银端 · Linux 收银镜像 · 安卓平板端 · 管家 App · 自建服务端

---

## 1. 产品定位

| 项 | 内容 |
|---|---|
| **产品名** | 逸华餐饮收银 |
| **业态** | 餐饮（**正餐** + **快餐**，同一套程序双模式切换） |
| **目标客户** | 中小餐饮商家（单店起步，架构支持连锁） |
| **部署形态** | 私有化部署（商家自己的服务器/云主机）/ 本地一体化 |
| **目标硬件** | x86_64 工控机 / 一体机 / 收银机，2~4 核低功耗 CPU，4GB 内存 |
| **操作系统** | Windows 7 SP1+ / Windows 10 / Linux（x64，ARM64 备选） |

### 1.1 两种业态的差异

| 维度 | 正餐模式（中餐/火锅） | 快餐模式（小吃/奶茶） |
|---|---|---|
| 主流程 | 开台 → 点单 → 加菜 → 结账 → 清台 | 点单 → 收款 → 出取餐码 → 叫号 |
| 桌台 | **必须有**，支持换台/并台/拼台 | 无桌台 |
| 挂单 | 支持（一桌多单） | 不需要 |
| 出餐 | 后厨分档口打印 | 取餐号 + 叫号屏 |
| 客单价 | 高 | 低，**要求下单快** |
| 界面重心 | 桌台图 + 菜品分类 | 菜品大图 + 快捷结账 |

**实现方式**：同一个程序，用「门店模式」配置切换。`store_mode = 1` 正餐 / `2` 快餐。

## 3. 非功能需求

### 3.1 性能（**关键约束**）

| 指标 | 目标 | 说明 |
|---|---|---|
| 冷启动 | ≤ 8 秒 | 在 4GB / 机械硬盘设备上 |
| 点单响应 | ≤ 100ms | 点击到界面反馈 |
| 结账 | ≤ 500ms | 含打印 |
| 内存占用 | ≤ 300MB | 稳态 |
| 安装包体积 | ≤ 250MB | |
| 磁盘占用 | ≤ 500MB | 含数据库 |

### 3.2 兼容性

| 项 | 范围 |
|---|---|
| 操作系统 | Windows 7 SP1+ / Windows 10 / Linux（Debian 11+） |
| 架构 | x86_64（主）/ ARM64（备选） |
| 屏幕分辨率 | 1024×768 起，支持 1366×768 / 1920×1080 |
| 触屏 | 必须支持（收银机以触摸为主） |

### 3.3 外设兼容

| 外设 | 协议 | 支持方式 |
|---|---|---|
| 小票打印机 | **ESC/POS** | USB / 串口 / 网口(TCP 9100) / 蓝牙 |
| 标签打印机 | **TSPL / CPCL** | 同上 |
| 电子秤 | 厂商串口协议 | 需逐个适配，**优先支持**：大华、托利多、顶尖、凯士、易衡、长飞 |
| 扫码枪 | HID 键盘 | 零适配 |
| 钱箱 | ESC/POS 开箱指令 | 打印机 RJ11 |
| 客显 | ESC/POS / 串口 | VFD / LCD |
| 副屏 | 应用自渲染 | HDMI |

### 3.4 可靠性

| 项 | 要求 |
|---|---|
| 断网可用 | **必须** —— 点单、结账（现金/记账）、打印全部本地完成 |
| 断电保护 | SQLite WAL 模式；Linux 只读根 + overlay |
| 数据不丢 | 本地订单进 outbox 队列，联网后幂等补传 |
| 崩溃恢复 | 启动时检查未完成订单 |

### 3.5 安全

| 项 | 要求 |
|---|---|
| 通信 | HTTPS（生产必须） |
| 密码 | bcrypt 存储 |
| 权限 | 角色 + 权限点，敏感操作需二次验证 |
| 数据 | 多租户隔离（`tenant_id` 强制过滤） |

## 5. 一期范围（MVP）

### 做

```
✅ 登录（含离线登录）
✅ 商品（同步 + 浏览 + 搜索）
✅ 点单全流程（正餐 + 快餐）
✅ 结账（现金 + 自定义记账）
✅ 打印（小票 + 后厨 + 标签）
✅ 交班
✅ 订单查询 + 退单 + 反结账
✅ 桌台（正餐）
✅ 取餐号（快餐）
✅ 设置（打印机/电子秤/收银参数）
✅ 数据同步 + 离线队列
✅ 服务端（约 30 个接口）
```

### 不做（预留接口）

```
⬜ 发票（接口预留）
⬜ 会员（表和接口预留）
⬜ 库存（表预留）
⬜ 报表（一期只做最基础的营业汇总）
⬜ 线上支付（只做记账，接口预留）
⬜ 营销 / 优惠券
⬜ 刷脸支付（已确认不需要）
⬜ 多门店 / 连锁
```

## 6. 验收标准（一期）

| 编号 | 标准 |
|---|---|
| A-01 | 在 4GB / 机械硬盘的 Win7 设备上冷启动 ≤ 8 秒 |
| A-02 | 断网状态下能完成：点单 → 结账（现金）→ 打印 → 交班 |
| A-03 | 断网期间产生的订单，联网后自动补传且不重复 |
| A-04 | 小票机（ESC/POS）即插即用，无需装驱动 |
| A-05 | 支持至少 3 个品牌电子秤自动识别 |
| A-06 | 后厨分档口打印正确路由 |
| A-07 | 交班现金差异计算正确 |
| A-08 | 正餐/快餐模式切换后界面和流程正确 |
| A-09 | 安装包 ≤ 250MB，内存占用 ≤ 300MB |
| A-10 | Linux 镜像从开机到收银界面 ≤ 20 秒 |
