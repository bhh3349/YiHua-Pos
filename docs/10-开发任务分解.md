# 逸华餐饮收银 —— 开发任务分解（AI 协作版）

> **使用说明**：本文档是给 AI 开发者执行的任务清单。
> 每个任务都是**自包含**的：有明确的目标、输入、输出、验收标准。
> 建议每个任务单独开一个 AI 会话，把「任务卡片」+「技术方案」一起给它。

---

## 0. 执行约定

### 0.1 技术栈（不可更改）

```
客户端  .NET 8 + Avalonia UI 11 + Prism + DryIoc + SqlSugar(SQLite)
        单目标 net8.0，两个 RID：linux-x64（主力）/ win-x64
服务端  FastAPI + SQLAlchemy 2 + MySQL 8（已实现，见 server/）
```

### 0.2 平台优先级（**影响所有任务的实现顺序**）

| 平台 | 设备 | 优先级 |
|---|---|---|
| **Linux** | 低配触屏一体机 | ⭐ **主力，所有硬件先做 Linux** |
| Windows | 台式机（Win10+） | 次要，可延后 |

> 不考虑 Windows 7。不做 .NET Framework 分支。

### 0.2 编码规范

| 项 | 要求 |
|---|---|
| 语言 | C# 12 / Python 3.12 |
| 命名 | 类 PascalCase，方法 PascalCase，私有字段 `_camelCase` |
| 异步 | 一律 `async/await`，禁止 `.Result` / `.Wait()` |
| 依赖注入 | 构造函数注入，禁止服务定位器（除 ViewModel 内 Prism 的 `_containerProvider`） |
| 平台判断 | 只允许在 `Hardware/Windows` 和 `Hardware/Linux` 内出现 |
| 测试 | 每个 Service 必须有单元测试 |

### 0.3 每个任务的交付标准

```
✅ 代码可编译通过（dotnet build 无 error）
✅ 有对应的单元测试且通过
✅ 无 TODO / 无硬编码路径 / 无明文密钥
✅ 提交时附：改动文件清单 + 测试结果截图或输出
```

### 0.4 任务状态标记

```
[ ] 未开始   [~] 进行中   [x] 已完成   [!] 阻塞
```

## 阶段总览

| 阶段 | 内容 | 任务数 |
|---|---|---|
| **M-1** | **技术验证原型**（在真机一体机上验证 Linux + Avalonia） | 1 |
| **M0** | 基础设施（项目骨架 / 数据层 / 主题 / 控件库） | 5 |
| **M1** | 硬件层（打印 / 电子秤 / 钱箱 / 客显）— **Linux 优先** | 7 |
| **M2** | 服务端补齐（P0 接口）+ **Linux 镜像构建** | 5 |
| **M3** | 客户端业务（登录 / 商品 / 点单 / 支付 / 交班 / 报表 / 设置） | 11 |
| **M4** | 离线与同步 | 3 |
| **M5** | 打包发布（Linux 镜像定稿 / Windows 安装包） | 3 |
| **M6** | 二期（安卓端 / 管家 App） | 待定 |

**关键路径**：M-1 → M0 → M1(Linux 打印) → M3(点单) → M4(离线) → M5

> **平台优先级**：低配触屏一体机走 **Linux 镜像**（主力），台式机走 **Windows**（次要）。
> 因此所有硬件实现**先做 Linux**，Windows 版可延后。

**目标**：在**真实的目标一体机**上验证「Linux 镜像 + Avalonia」这条路走得通

**为什么必须先做**：这是整个项目最大的技术风险。花 1-2 天排掉，比开发 3 个月后发现不行划算得多。

├── deploy/proto-image/        Debian minimal + 图形栈 + 应用自启
└── 验证报告.md

**验证清单**
| 编号 | 验证项 | 通过标准 |
|---|---|---|
| V-1 | 一体机能装 Debian 12 + 图形栈 | 能进桌面 |
| V-2 | 触摸屏可用 | 能点击 |
| V-3 | Avalonia 应用全屏启动 | 无花屏/闪烁 |
| V-4 | 冷启动时间 | **≤ 8 秒** |

# M5 打包发布

## [ ] T-501 Linux 镜像构建（**主力交付形态**）

**交付物**：`deploy/linux-image/`

```
build.sh             构建脚本（debootstrap + 定制）
overlay/             覆盖层（服务配置、启动脚本、udev 规则）
installer/           U 盘刷机程序
```

**要求**
| 项 | 要求 |
|---|---|
| 基础系统 | Debian 12 minimal |
| 图形栈 | Wayland（Weston）或最小 X11，**无桌面环境** |
| 根文件系统 | **只读** + overlayfs（写操作重定向） |
| 分区 | A/B 双分区（远程升级 + 失败回滚） |
| 启动 | systemd → 自动登录 → 收银应用全屏 |
| 外设权限 | 预置 udev 规则 + 用户组 |
| 体积 | 镜像 ≤ 2GB |

**验收**
- 虚拟机 + 真实一体机上，开机到收银界面 ≤ 20 秒
- 断电重启自动恢复
- 远程升级失败能自动回滚

**依赖**：T-103, T-105, M0-M4 完成
