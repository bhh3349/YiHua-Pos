## 1. 响应格式（两种）

### 格式一：ResponseBase（登录类接口）

```json
{"code": "200", "msg": "成功", "data": { ... }}
```

### 格式二：ApiResponse + 二次编码（业务接口）

```json
{"code": 200, "data": "{\"areaList\":[...]}", "success": true, "trace_no": "..."}
```

> ⚠️ **注意**：格式二的 `data` 是**二次编码的 JSON 字符串**，需要 `json.loads(data)` 再解析。
