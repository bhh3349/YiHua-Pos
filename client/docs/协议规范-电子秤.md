# 电子秤串口协议规范

> 本文档是**协议事实说明**（波特率、帧结构、指令字节），用于实现串口秤驱动。
> 协议本身是公开技术标准，本文档为独立整理，不含任何第三方代码。

---

## 1. 通用约定

### 1.1 串口默认参数

| 参数 | 值 |
|---|---|
| 波特率 | **9600**（默认） |
| 数据位 | 8 |
| 校验位 | None |
| 停止位 | 1 |
| 流控 | None |

**特殊波特率**：

| 品牌 / 型号 | 波特率 |
|---|---|
| 顶尖 OS2X | 9600 |
| 容大 E1 | 19200 |
| 壹佳一 C_S1 | 115200 |
| 其余 | 9600 |

### 1.2 取重频率

默认 **100ms** 一次（可配置）。实现要点：
- 定时器触发取重
- **数据未变化时不重复上报**（去重）
- 环形缓冲 8 帧，把多次读取的数据拼接后再解析（处理粘包/半包）

### 1.3 开钱箱（走秤的串口）

```
1B 70 00 3C E1     (27, 112, 0, 60, 225)
```

### 1.4 状态枚举

| 状态 | 含义 |
|---|---|
| `Stable` | 稳定（可取数） |
| `Weighting` | 晃动中（不可取数） |
| `OverLoad` | 超载 |
| `UnWeight` | 空秤（重量为 0） |
| `NegativeWeight` | 负重量 |
| `Error` | 解析错误 |
| `Empty` | 无数据 |

## 2. 大华 Aclas OS2X

**品牌：大华（Aclas）** · **型号：OS2X / PS1X** · **串口：9600 8N1**

### 2.1 指令表

| 用途 | 字节（HEX） |
|---|---|
| 初始化 | `3C 50 42 3E 09` |
| 取重 | `11` |
| 置零 | `3C 5A 4B 3E 09` |
| 去皮 | `3C 54 4B 3E 09` |

**初始化时机**：连接建立后立即发送。
**置零重试**：失败时重试 3 次，间隔 100ms。

### 2.2 帧格式（**定长 15 字节**）

```
偏移  长度  含义
────  ────  ──────────────────────────────────────
[0]    2    帧头  01 02
[2]    1    状态字符（ASCII）
              'S' = 稳定
              'U' = 晃动
              'F' = 超载
[3]    7    重量值（ASCII，空格右填充，逗号作小数点）
              例："  1,250"  →  1.250
[10]   2    单位（ASCII）
              例："kg" / "g"
[12]   3    保留 / 校验
```

### 2.3 解析算法

```
1. 在缓冲区里从后往前找帧尾 03 04
2. 从帧尾位置往前推 15 字节，即为帧首
3. 校验 [0..1] == 01 02
4. 取 [2] 判状态
5. 取 [3..9] 转字符串 → 去空格 → 逗号换句点 → decimal
6. 取 [10..11] 单位 → 换算成 kg
7. 重量为 0 → UnWeight；重量 < 0 → NegativeWeight
```

### 2.4 单位换算

| 单位 | 换算 |
|---|---|
| `kg` | ×1 |
| `g` | ÷1000 |

## 3. 托利多 ArivaS

**品牌：梅特勒-托利多（Toledo）** · **型号：ArivaS / FreshStar / ACS-SY** · **串口：9600 8N1**

### 3.1 指令表

| 用途 | 字节（HEX） |
|---|---|
| 取重 | `04 02 31 33 03` |
| 置零 | `04 02 31 31 03` |
| 去皮 | `04 02 31 32 03` |

指令格式：`EOT(04)` + `STX(02)` + `"13"/"11"/"12"` + `ETX(03)`

### 3.2 帧格式（**定长 31 字节**）

```
偏移  长度  含义
────  ────  ──────────────────────────────────────
[0]    1    帧头  02 (STX)
[4]    1    稳定标志
              0x30 ('0') = 稳定
              其他       = 不稳定
[6]    5    重量值（ASCII）
              特殊值：
                "uuuuu" = 错误
                "^^^^^" = 超载
[11]  20    其余字段（皮重、单价、金额等，本实现暂不使用）
```

### 3.3 解析算法

```
1. 缓冲区长度 ≥ 31
2. 从后往前找帧尾 03 (ETX)
3. 往前推 31 字节得帧首，校验 [0] == 02
4. 取 [4] 判稳定（0x30 = 稳定）
5. 取 [6..10] 转字符串
     - "uuuuu" → Error
     - "^^^^^" → OverLoad
     - 其他 → 解析数字
6. 单位固定为克 → ÷1000 得 kg
7. 保留 3 位小数
```

## 4. 凯士 CAS216

**品牌：凯士（CAS）** · **型号：CAS216** · **串口：9600 8N1**

### 4.1 特性

| 项 | 说明 |
|---|---|
| 通信方式 | **被动接收**（秤主动推送，不发送取重指令） |
| 置零 | ❌ 不支持 |
| 去皮 | ❌ 不支持 |
| 开钱箱 | ❌ 不支持（走秤的串口不行） |

### 4.2 帧格式（**定长 12 字节**）

```
偏移  长度  含义
────  ────  ──────────────────────────────────────
[0]    8    重量值（ASCII，8 字节，空格左填充）
              例："   1.250"
[8]    2    单位（ASCII，去空格后匹配）
              "g"  → 克
              "kg" → 千克
```

### 4.3 解析算法

```
1. 缓冲区长度 ≥ 12
2. 取 [0..7] 转 ASCII 字符串 → 去空格 → decimal
3. 取 [8..9] 转 ASCII 字符串 → Trim
4. 若单位为 "g" → ÷1000
5. 保留 3 位小数
6. 重量为 0 → UnWeight；重量 < 0 → NegativeWeight
```

## 6. 实现建议

### 6.1 协议解析与串口 IO 分离

```
IScaleProtocol.TryParse(ReadOnlySpan<byte> frame, out decimal weight)
    ↑ 纯函数，无 IO，可直接单元测试

SerialScale
    ↑ 负责串口读写 + 缓冲 + 调用协议解析
```

### 6.2 帧同步要点

| 问题 | 处理 |
|---|---|
| 粘包（一次读到多帧） | 环形缓冲累积，按帧尾切分，取最后一帧 |
| 半包（帧不完整） | 累积到下次读取，长度不足直接丢弃 |
| 噪声数据 | 找不到帧头/帧尾 → 返回 Error，不抛异常 |
| 缓冲溢出 | 缓冲上限 8 帧，超出丢弃最旧的 |

### 6.3 自动探测

```
for 每个串口 in 系统串口列表:
    for 每个协议 in 协议注册表:
        打开串口(该协议波特率)
        发送取重指令
        等待 ≤500ms
        若收到合法帧 → 命中
        关闭串口
```

探测顺序建议按市场占有率：大华 → 托利多 → 凯士 → 其余。
