## 6. 技术规格

### 6.1 钱箱（走打印机）

**开箱指令（ESC/POS 标准）**：

```
ESC p m t
  1B 70 00 19 FA     (m=0, t=25, 200)  ← 常用
  1B 70 00 3C E1     (m=0, t=60, 225)  ← 另一种脉冲参数
```

钱箱接在打印机的 **RJ11 口**，所以「开钱箱」= 往打印机发这 5 个字节。

**实现要点**：
- 依赖 `IReceiptPrinter`（已冻结接口）
- 如果打印机不支持，要能优雅降级（记日志，不抛异常）

### 6.2 VFD 客显（串口）

**常见协议**：ESC/POS 兼容的显示指令

```
清屏         0C
光标定位     ESC l <行> <列>    (1B 6C 行 列)
显示字符串   <ASCII 字节>
亮度         ESC * <n>          (1B 2A n)
初始化       ESC @              (1B 40)
```

**典型 VFD 规格**：20 字符 × 2 行

**显示布局建议**：
```
行1:  商品名（截断到 20 字符）
行2:  "合计 128.00  找零 12.00"
```

**实现要点**：
- 支持中英文（VFD 通常只支持 ASCII，中文要转码或降级为拼音/数字）
- 金额右对齐
- 超长文本截断

### 6.3 副屏

副屏是**第二块 HDMI 显示器**，由应用自己渲染（不是外设协议）。

**交付要求**：
- `SecondaryScreenManager` 负责：检测第二块屏、开全屏窗口、推送数据
- 用 Avalonia 实现（项目已用 Avalonia 11）
- 支持三种状态：空闲（欢迎语/广告）、点单中（商品+金额）、结账（实收+找零）
- **本任务只做管理器和数据模型**，具体视图可简单实现

## 9. 模型设计

```csharp
public enum PaperWidth { Mm58 = 58, Mm80 = 80 }

public class PrintTemplate
{
    public string Name { get; set; } = "";
    public PaperWidth Paper { get; set; } = PaperWidth.Mm80;
    public List<TemplateElement> Elements { get; set; } = new();
}

public abstract class TemplateElement
{
    public AlignStyle Align { get; set; } = AlignStyle.Left;
    public bool Bold { get; set; }
    public int FontWidth { get; set; } = 1;   // 1-8 倍
    public int FontHeight { get; set; } = 1;
}

public class TextElement : TemplateElement
{
    public string Text { get; set; } = "";    // 支持 {变量}
}

public class TableElement : TemplateElement
{
    public string[] Columns { get; set; } = Array.Empty<string>();
    public int[] Widths { get; set; } = Array.Empty<int>();  // 字符宽度
    public string DataSource { get; set; } = "";             // 如 "items"
}

public class QrCodeElement : TemplateElement
{
    public string Content { get; set; } = "";  // 支持 {变量}
    public int Size { get; set; } = 6;
}
```

## 10. 变量系统

模板里用 `{变量名}` 占位，渲染时替换：

| 变量 | 含义 |
|---|---|
| `{storeName}` | 门店名 |
| `{storePhone}` | 门店电话 |
| `{storeAddress}` | 门店地址 |
| `{orderNo}` | 订单号 |
| `{takeNo}` | 取餐号 |
| `{deskName}` | 桌台名 |
| `{guestCount}` | 就餐人数 |
| `{items}` | 商品明细（配合 TableElement） |
| `{amountTotal}` | 商品总额 |
| `{amountDiscount}` | 折扣 |
| `{amountPay}` | 应付 |
| `{amountReceived}` | 实收 |
| `{amountChange}` | 找零 |
| `{payTypeName}` | 支付方式 |
| `{operatorName}` | 收银员 |
| `{createdAt}` | 下单时间 |
| `{settleTime}` | 结账时间 |
| `{remark}` | 备注 |

**要求**：
- 未知变量原样保留（不崩）
- 金额格式化：两位小数，右对齐
- 时间格式化：`yyyy-MM-dd HH:mm:ss`

## 11. 内置默认模板（必须提供）

| 模板 | 用途 | 内容要点 |
|---|---|---|
| **前台小票** | 结账打印 | 门店信息 / 桌号 / 商品明细表 / 合计 / 支付 / 找零 / 二维码 |
| **后厨单** | 分档口打印 | 桌号 / 时间 / 菜品 + 数量 + 备注（**不放金额**） |
| **标签** | 茶饮杯贴 | 取餐号（大字）/ 商品名 / 规格 / 时间 |
| **交班单** | 交班打印 | 班次时间 / 订单数 / 各支付方式金额 / 现金核对 |
