## 3. 功能要求

### 3.1 登录流程（三步）

```
① 门店选择 → ② 账号密码 → ③ 登录成功进主界面
```

**① 门店选择**
- 从服务端拉门店列表（离线时用本地缓存的上次门店）
- 显示门店名 + 地址
- 支持手动输入门店编号（网络不通时用）
- 记住上次选择

**② 账号密码**
- 数字键盘输入（收银员习惯）
- 密码框：可切换明文/密文
- 错误提示：账号不存在 / 密码错误 / 账号已停用 / 网络异常 —— **要区分清楚，不能都报"登录失败"**
- 连续失败 5 次锁定 5 分钟

**③ 登录成功**
- 拿 token + 用户信息 + 权限清单
- 存到本地（后续请求带 token）
- 触发主界面跳转（**通过事件通知，不要直接引用 MainWindow**）

### 3.2 权限

登录返回的权限清单决定菜单显示与按钮可用性：

| 角色 | 权限 |
|---|---|
| 店长 | 全部 |
| 收银员 | 点单/结账/开台，**不能**：改价、退菜、交班、改商品 |
| 服务员 | 点单，**不能**：结账 |
| 厨师 | 只看后厨单，**不能**：前台界面 |

**要求**：
- 提供 `IPermissionService`，能判断 `HasPermission(PermissionCode.XXX)`
- 提供 `[RequirePermission]` 特性的用法说明（**不要真的接入AOP**，太重）
- 无权限的菜单**不显示**，不是显示成灰色

### 3.3 离线登录

**这是关键需求**：门店网络断了，收银还得继续干活。

```
- 登录时先试服务端
- 服务端不可达 → 读本地缓存的用户凭据 + 上次权限清单
- 本地有缓存 → 允许登录，标记为「离线模式」
- 本地没有 → 提示「首次使用需要联网激活」，不给进
```

离线模式下：
- 右上角显示离线标识
- 所有写操作进 outbox 队列（数据层已支持）
- 恢复网络后自动同步

## 4. UI 工艺要求（硬性）

必读 `client/tasks/T-005_控件库_仓鼠3号.md` 第 3 节（反 slop 禁令）。

**登录页的 Craft Read 参考**（你可以调整，但要说明理由）：
- `CRAFT_LEVEL` 7 / `MOTION_INTENSITY` 2 / `VISUAL_DENSITY` 4 / `DESIGN_VARIANCE` 3
- 签名动作建议：**门店选择与账号输入在同一屏，用分段控件切换**，减少收银员等待时的点击次数

**必须覆盖的状态**：
```
idle / loading / empty / error / success / offline
```
其中 **loading / empty / error 是阻塞级**，未定义不许交付。

**收银场景注意**：
- 触控目标 ≥ 44px
- 数字键盘用 `NumberPad`（已有）
- 不用 emoji 当图标
- 错误提示要说清「发生了什么 + 怎么修」，不道歉不含糊
